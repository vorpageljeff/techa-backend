# Frontend

Esta pasta concentra os clientes web do projeto.

- `site`: site institucional/landing page para Vercel.

O app operacional Android, iOS e web mobile usa a base recuperada em
`../../techa-mobile-recuperado/` e está publicado em
`https://techa-mobile-web.vercel.app`.

A pasta `mobile/` deste repositório é um cliente legado de demonstração; não a use
como fonte para publicar a web mobile atual.
