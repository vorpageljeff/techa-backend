# Techa Site

Site institucional em React/Vite para apresentar a solucao e direcionar usuarios ao app.

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy no Vercel

Configure o projeto da Vercel com:

- Root directory: `frontend/site`
- Build command: `npm run build`
- Output directory: `dist`

Variaveis opcionais:

```env
VITE_API_BASE_URL=https://techa-api.2.25.189.129.nip.io
VITE_APP_URL=https://techa-mobile-web.vercel.app
```
